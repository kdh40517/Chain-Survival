# Chain Survival

> 근접 공격을 적중시키면 장착한 스킬 6개가 확률적으로 연쇄 발동하는 2D 로그라이트 생존 게임

## 이런 게임입니다

대부분의 뱀서라이크는 스킬 발동을 전부 자동에 맡깁니다. Chain Survival은 **플레이어의 조작을 방아쇠로 되돌려 놓는 것**을 목표로 만들었습니다.

칼을 휘둘러 적을 맞히면 그 순간 **체인 리액션**이 시작됩니다. 1단 스킬이 확률로 발동하고, 성공하면 2단으로 넘어가고, 실패하면 거기서 연쇄가 끊깁니다. 끝까지 이어질 확률은 낮지만 그만큼 위력이 가파르게 증폭되기 때문에, "이번 한 방이 어디까지 터질까"가 전투의 긴장감을 만듭니다.

## 핵심 시스템 — 체인 리액션

근접 공격 적중 → 슬롯 1번부터 순차적으로 발동 판정 → 성공 시 다음 단계로, 실패 시 즉시 종료.

| 단계 | 발동 확률 | 데미지 배율 | 범위 배율 |
|:---:|:---:|:---:|:---:|
| 1단 | 10% | 1.5× | 1.0× |
| 2단 | 15% | 2.0× | 1.0× |
| 3단 | 20% | 3.0× | 2.0× |
| 4단 | 5% | 5.0× | 3.0× |
| 5단 | 3% | 7.0× | 5.0× |
| 6단 | 1% | **10.0×** | **10.0×** |

- 단계가 오를수록 데미지와 범위가 함께 증폭되고, 스킬별로 6단 전용 연출이 따로 있습니다 (전 방향 산탄, 화면 단위 충격파 등)
- 각 단계는 0.15초 간격으로 발동해 연쇄가 눈으로 읽히도록 했습니다
- 체인 진입점에 0.2초 재발동 가드를 두어, 한 번의 타격에는 반드시 한 번의 체인만 발생합니다

## 게임 플레이

**조작**

| 키 | 동작 |
|:---:|:---|
| `WASD` / 방향키 | 이동 |
| `Space` | 근접 공격 (2타 콤보) |
| `Z` | 대시 (무적) |
| `ESC` | 일시정지 / 옵션 |

**성장**

- 적 처치 → 경험치 보석 획득 → 레벨업 시 카드 3장 중 1장 선택
- 카드는 **액티브 스킬 / 패시브 스탯 / 스킬 강화** 3종류, 등급은 **Normal / Rare / Legendary** 3단계
- 총 **40여 종**의 카드를 등장 가중치(`dropWeight`) 기반 룰렛으로 추첨하며, 이미 장착한 스킬·보유하지 않은 스킬의 강화 카드는 후보에서 제외해 선택지가 낭비되지 않도록 했습니다
- 시간이 지날수록 적 스폰 간격이 짧아져 후반으로 갈수록 밀도가 높아집니다

**액티브 스킬 6종**

화염 장판 · 파이어볼 · 번개 · 공전검 · 충격파 · 토네이도

## 기술적으로 신경 쓴 부분

**1. 판정의 주체를 공격 행위로 통일**

초기 구조에서는 적이 각자 공격 판정에 닿는 순간 스스로 체인을 요청했습니다. 그래서 적 5마리를 한 번에 맞히면 체인도 5번 발동해 이펙트가 폭주하고 프레임이 떨어졌습니다. 적마다 중복 플래그를 붙이는 대신 **판정의 주체를 적이 아니라 공격 행위로 재정의**하고, 체인 진입점 한 곳에서 재발동 가드로 중복 호출을 흡수하도록 바꿨습니다. 같은 원인이던 타격음 중첩(사운드 클리핑)도 정적 타임스탬프로 재생 빈도를 제한하고 음높이를 무작위화해 함께 해결했습니다.

**2. 데이터 주도 스킬 구조**

스킬 6종은 각자 필요한 강화 수치가 전부 다릅니다(폭발 반경, 발사 개수, 지속 시간, 타격 틱, 부채꼴 각도, 공전검 개수 등). 이를 `SkillEffect` 추상 부모로 공통 규격을 통일하고, 강화 수치는 `skillId`를 키로 하는 딕셔너리에 분리 저장했습니다. 카드 데이터는 `ScriptableObject`로 외부화해서, **새 스킬 추가 시 매니저 코드를 수정하지 않고** 스크립트·프리팹·데이터 에셋만 만들면 되도록 했습니다.

**3. 지속 타격 판정**

공전검·화염 장판처럼 범위에 머무는 스킬은 `OnTriggerStay2D`가 매 프레임 호출되어 적이 즉사하는 문제가 있었습니다. 적별 마지막 피격 시각을 딕셔너리로 관리해 일정 간격(틱)마다만 데미지가 들어가도록 처리했습니다.

**4. 무한 스크롤 맵**

3×3 타일을 재활용해, 플레이어가 타일 크기의 1.5배 이상 벗어나면 반대편으로 이동시키는 방식으로 끊김 없는 필드를 구현했습니다.

## 프로젝트 구조

```
Assets/Scripts/
├── GameManager.cs        // 레벨업·카드 추첨·강화 수치 저장·일시정지
├── ChainManager.cs       // 체인 리액션 파이프라인
├── PlayerController.cs   // 이동·콤보 공격·대시·피격
├── EnemyController.cs    // 추적/공격 AI·피격·드롭
├── SkillEffect.cs        // 모든 스킬의 추상 부모
├── SkillData.cs          // 카드 정의 (ScriptableObject)
└── ...Skill.cs           // 액티브 스킬 6종
```
